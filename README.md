# Metro Analytics Hub

## Competition & Member Intelligence Platform for Student Organizations

A role-based analytics platform prototype designed to centralize competition management, team formation, member engagement, and organizational insights for university analytics clubs.

> **Status:** Portfolio Prototype (Frontend Demonstration)  
> **Live Demo:** https://metro-analytics-club.vercel.app

---

# Overview

Student organizations often manage competitions, project teams, and member engagement using spreadsheets, messaging apps, and multiple disconnected tools. This project explores how these workflows can be unified into a centralized analytics platform that improves collaboration, accountability, and visibility across the organization.

Although implemented as a frontend prototype, the application models how organizational data can be structured, managed, and visualized within a scalable software system.
